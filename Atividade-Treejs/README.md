# Atividade Tree.js

## Instruções

1. Instale as dependências do projeto:

```bash
npm install
```

2. Instale o Three.js, se ainda não estiver instalado:

```bash
npm install three
```

3. Execute o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abra o navegador em `http://localhost:5173` ou na porta exibida pelo Vite.

## Como trocar o exercício

No arquivo `index.html`, altere a linha do script para carregar o arquivo de exercício desejado:

```html
<script type="module" src="/src/ex1.js"></script>
```

Substitua `ex1.js` por `ex2.js`, `ex3.js`, `ex4.js` ou outro arquivo de exercício que você queira executar.

Exemplo:

```html
<script type="module" src="/src/ex2.js"></script>
```

## Observações

- O projeto usa Vite e módulos ES.
- Se o navegador não abrir automaticamente, acesse manualmente a URL fornecida pelo Vite.
- Certifique-se de que o pacote `three` esteja instalado, pois os exercícios usam o Three.js.
